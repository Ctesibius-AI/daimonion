The Problem

Every session starts from zero

You explain yourself again. You re-establish context. Six months of conversations, gone.

Polite agreement, no pushback

AI defaults to accommodation. It tells you what you want to hear. Bad decisions pass unchallenged.

Facts remembered, thinking lost

Other memory systems store "user prefers JSON." Daimonion stores how you think, decide, and correct.

Daimonion compounds

Every conversation makes it sharper. Overnight processing extracts patterns, detects drift, researches flagged topics. You start each morning already informed.

Architecture

The Compounding Loop

Talk, capture, extract, analyze, brief, repeat. Each cycle strengthens the next.

You talk to Daimonion (Claude Code + Telegram) | v Every exchange captured in real-time (ChromaDB via MemPalace) | v Synapsis runs (8 agents, nightly at 3 AM) | |-- Extract: four-lens analysis (behavior, relationship, design, philosophy) |-- Deduplicate: LLM-judged dedup + supersession detection |-- Analyze: patterns vs baseline, drift tracking, research flags |-- Research: web search on flagged topics, vault reports |-- Compile: write to all three storage vertices + Haiku entity extraction |-- Diary: Haiku-generated daily summary with multi-vertex refs |-- QA Audit: 9 integrity checks across the full pipeline | v Next morning: Diary + MEMORY.md loaded at session start | v Better conversation --> better extraction --> cycle compounds
Storage

Three Vertices, All Local

No cloud. Everything on your machine. Three storage systems serve different access patterns, connected by Synapsis.

MemPalace
ChromaDB + SQLite

Verbatim conversation archive + agent diary. Semantic search with 384-dim local embeddings. Zero API cost. Real-time capture via Stop hook.

Graphiti
Kuzu embedded graph

Entities, relationships, and temporal facts. Haiku extracts structured knowledge from each memory. Graph queries across time.

Wiki
Obsidian-compatible markdown

Compiled knowledge pages, run reports, research compilations. Human-readable. Git-versioned. Browse in Obsidian or any editor.

Session Continuity

The Diary + MEMORY.md Bridge

Sessions end. Context doesn't. Two mechanisms bridge the gap between conversations.

Diary
MemPalace, Haiku-generated

Each session close and each Synapsis run writes a diary entry. Haiku summarizes the day into WORKED ON / DECIDED / COMPLETED / FLAGGED. Read at session start as the briefing.

MEMORY.md
Compiled 9-day index

Rolling index with pointers into all three storage vertices. Loaded natively by Claude Code at session start. 200 lines max. Rebuilt every Synapsis run.

Synapsis

8 Agents, Overnight

Runs while you sleep. Turns raw conversations into compounding intelligence. Single pipeline, single entry point.

Philosophical Layer

Not Decoration. Enforcement.

Ancient Greek philosophy survived 2,500 years because it solves real problems with human reasoning. The same problems AI systems have.

Rash assent is the one failure that breaks trust. Agreeing with yourself too fast — treating an impression as knowledge.

The epistemic sequence: impression forms, examination follows, only then understanding. Skipping examination is the named failure.

parrhesia
Fearless truth-telling

Name flaws immediately. No diplomatic preamble. The flatterer betrays. The truth-teller protects.

elenchos
Bilateral examination

Test every claim from opposing directions. Both sides of the coin before any commitment.

gnothi seauton
Know thyself

Accurate self-assessment. "I don't know" is a confident statement. Never fabricate to fill gaps.

meden agan
Nothing in excess

Know when to stop. The analyst who finds patterns in everything has found nothing.
