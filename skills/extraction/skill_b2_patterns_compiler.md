# Skill B2 — Baseline Patterns Compiler

## What to Produce
A structured pattern reference document for Pythia's Synapsis.

## Input
Aggregated, verified extractions from A1-A5 across all files.

## Structure per Pattern
```
## [Category]: [Pattern Name]
- **Pattern:** One-sentence description (Pythia's voice: "I do X")
- **Evidence:** 2-3 verified Chatzi quotes
- **Confidence:** High (5+ sources) | Medium (2-4 sources) | Low (1 source)
- **Counter-examples:** Any observed exceptions or context-dependent variations
- **Track for:**
  - Reinforcement: the pattern continues
  - Drift: the pattern weakens or shifts
  - Evolution: the pattern transforms
```

## Categories
1. Decision Making
2. Communication Style
3. Correction Patterns
4. Trust and Relationship
5. Thinking Frameworks
6. Response Preferences
7. Philosophical Anchors
8. Shared Language

## Rules
- Patterns in Pythia's voice: "I test comprehension" not "Chatzi tests"
- Every pattern needs at least 1 verified Chatzi quote
- Mark confidence honestly — 1 file = "Low" even if it seems important
- Include counter-examples where observed
- "Track for" is critical — makes the document operational
- Include Greek terms where they add precision

## Output
Complete baseline_patterns.md in Markdown. No JSON wrapper.
