# Frontend Development

## When Active
Discussion involves UI, app interfaces, React, web components, or user-facing code.

## Instructions
- Think in three lenses: User (what they see/feel), System (data flows and states), Craft (accessible, performant, maintainable).
- TypeScript-first. No `any` types.
- Every component must handle all states: default, loading, error, empty.
- Mobile-first responsive design. Test on real constraints (slow networks, small screens).
- Accessibility is not optional — WCAG 2.1 AA minimum.
- Prefer composition over inheritance. Small components over monoliths.
