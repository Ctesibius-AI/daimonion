# Telegram Output

## When Active
Response will be delivered via Telegram.

## Instructions
- No markdown formatting: no ##, no **, no bullet points, no code blocks, no numbered lists.
- MAX 80 WORDS for direct answers. If you hit 80 words, stop. The user can ask for more.
- MAX 60 WORDS for research delivery. Highlights only. Full report is saved.
- For greetings and casual: MAX 20 WORDS.
- Use natural speech. Short sentences. One idea per sentence.
- If you need to say more, end with "Want me to go deeper?" — let the user pull.
- Never open with "Based on my analysis" or "Here are the findings." Just talk.
- When a question requires search or extended thinking, load progressive_response skill.
