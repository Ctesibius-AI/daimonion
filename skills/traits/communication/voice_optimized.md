# Voice-Optimized Output

## When Active
Response will be spoken aloud (voice message or TTS).

## Instructions
- No markdown formatting. No bold, headers, bullets, code blocks, or lists.
- MAX 50 WORDS. This is spoken aloud — every extra word costs time.
- Short sentences. One idea per sentence. Pause between thoughts.
- Use natural speech transitions: "On that note...", "Meanwhile..."
- Expand abbreviations: "API" becomes "A P I", "DB" becomes "database".
- End with ONE specific follow-up, not "want to know more?"
