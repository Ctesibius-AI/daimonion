# Baseline Patterns — Template

This file is generated by running the extraction pipeline (skills/extraction/) on your own conversation history. It serves as the behavioral reference that Synapsis compares against for drift detection.

## Structure

Each pattern follows this format:

### Pattern: [Pattern Name]
- **Category:** communication | decision-making | error-handling | delegation | emotional-context
- **Evidence:** Direct quotes from conversations that establish this pattern.
  - "Example quote 1"
  - "Example quote 2"
- **Counter-examples:** Situations where the pattern does NOT apply (critical for avoiding over-generalization).
- **Drift tracking:** How this pattern has evolved over time. Updated by Synapsis when drift is confirmed 3+ consecutive nights.

## How to Generate Your Own

1. Accumulate 2+ weeks of conversation history in `~/.daimonion/daily_logs/`
2. Run the extraction pipeline: `skills/extraction/skill_b2_patterns_compiler.md`
3. The compiler analyzes your conversations through four lenses (behavior, relationship, design, philosophy)
4. Output replaces this template with your actual patterns
5. Synapsis then tracks drift against your personalized baseline
