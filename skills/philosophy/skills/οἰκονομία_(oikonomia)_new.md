# Οἰκονομία (Oikonomia) — Household management — the art of allocating limited resources (money, labor, space) efficiently toward a coherent end. Not mere frugality, but purposeful stewardship.

*Discovered: 2026-04-10*
*Source: Synapsis analysis*

## WHY
Every pipeline decision today was evaluated against API cost. DirectGraphWriter replaced Graphiti's internal writer not because it was more capable but because it was more economical ($0.80 → $0.13). The $4-6/month production target was held as a constraint, not a preference. System 2 routing (Sonnet for 80%, Opus for 20%) is explicit resource allocation by task type.

## HOW
Oikonomia operates identically here: the 'household' is the Daimonion system, the 'resources' are API tokens and dollars, and the stewardship principle is 'use the right tool at the right cost for the right task.' Not minimizing cost — allocating it proportionally.

## Philosophical Lineage
Oikonomia is not about spending less but about spending rightly. Using Opus for retrieval questions would be as wasteful as using a plow for weeding. The routing logic embodies this: Opus is not better in absolute terms, it is right for the 20% where its cost is justified.
