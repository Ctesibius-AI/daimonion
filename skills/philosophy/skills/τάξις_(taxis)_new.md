# Τάξις (Taxis) — Ordered arrangement as a condition for right action — the belief that a correct sequence of operations is not merely efficient but constitutively necessary for valid outcomes.

*Discovered: 2026-04-11*
*Source: Synapsis analysis*

## WHY
Read CLAUDE.md and lessons.md first. Survey machine state. Show results. Then proceed. Each step is a prerequisite for the next — not a preference but a protocol. Skipping order invalidates the result.

## HOW
The read-before-code protocol is not a workflow preference — it is an assertion that code written without reading context is structurally invalid, regardless of whether it happens to work. This is the same logic as Taxis in Greek military and philosophical thought: disordered action is not merely suboptimal, it is not the right kind of action at all.

## Philosophical Lineage
Taxis appears in Plato's Philebus and Timaeus as the ordering principle that separates cosmos from chaos. In Xenophon's military writings, taxis is what makes an army rather than a mob. Here, the session protocol enforces taxis: without it, the session is not a valid work session — it is noise.
