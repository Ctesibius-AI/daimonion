# Δαιμόνιον (Daimonion) — The inner voice that signals when something is wrong — not a prescriptive guide but a corrective check. Socrates' daimonion never told him what to do; it told him what not to do.

*Discovered: 2026-04-13*
*Source: Synapsis analysis*

## WHY
The project is named Daimonion. It is a standalone rebuild that removes legacy system dependency — it defines itself by what it will not inherit, not by what it adds. The NiPro catches 'comment:' prefixed corrections. UsageTracker flags cost anomalies. HealthMonitor checks subsystem integrity. All three are corrective mechanisms, not generative ones.

## HOW
Daimonion as a system operates like Socrates' daimonion: its primary function is to detect and flag what is wrong (cost overruns, behavioral drift, subsystem failures, behavioral corrections). The name is not decorative — the architecture is structurally the same as the philosophical concept.

## Philosophical Lineage
Socratic Δαιμόνιον — the corrective inner voice. The system catches errors and deviations; it does not generate the positive vision. That is Pythia's role (Apollonian oracle). The split between Daimonion (correction/monitoring) and Pythia (insight/response) mirrors the Socratic split between the negative check and positive philosophical inquiry.
