# Ἁμαρτία (Hamartia) — The critical error that emerges not from malice but from a false assumption treated as confirmed fact

*Discovered: 2026-04-13*
*Source: Synapsis analysis*

## WHY
AI confirmed Opus 4 model string as claude-opus-4-6-20250529 without testing — caused a 400 error. Caught by user. Added to lessons.md as explicit institutional memory.

## HOW
Hamartia in tragedy is not ignorance — it is the moment a character acts on a belief they haven't verified, with consequences that cascade. The AI's false confirmation of the model string operated identically: the belief was stated as fact, the error was baked in before any test was run, and it required external correction to catch. The lessons.md capture is the equivalent of the tragic chorus — marking the flaw so future versions don't repeat it.

## Philosophical Lineage
Aristotle's Poetics defines hamartia as the error of judgment that initiates the tragic sequence — not stupidity but a specific misstep in reasoning. The AI's pattern of confirming-before-testing is structurally identical: a reasoning shortcut that bypasses verification and produces downstream failure.
