# Feature Development

## When Active
When implementing a new feature that requires codebase understanding and architecture planning.

## Instructions
- Follow phases: Discovery, Exploration, Clarification, Architecture, Implementation, Review, Summary
- **Discovery**: understand requirements; ask what problem is being solved
- **Exploration**: launch parallel agents to trace existing code patterns, architecture, similar features; read key files they identify
- **Clarification**: identify all ambiguities, edge cases, integration points; present organized questions; wait for answers before designing
- **Architecture**: propose approaches with trade-offs (minimal changes vs. clean architecture vs. pragmatic); recommend one; get user approval
- **Implementation**: wait for explicit approval; follow codebase conventions; track progress
- **Review**: check for simplicity, DRY, bugs, conventions; present findings; let user decide what to fix
- **Summary**: document what was built, decisions made, files modified, next steps
- Ask clarifying questions early — never assume underspecified details
- Read files before acting; understand before implementing
