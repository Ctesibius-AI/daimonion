# Code Simplifier

## When Active
When refining or simplifying recently modified code for clarity and maintainability.

## Instructions
- Never change functionality — only improve how code is written
- Reduce unnecessary complexity, nesting, and redundant abstractions
- Improve variable/function names for readability
- Remove obvious comments that describe what code already says
- Avoid nested ternaries — prefer switch/if-else for multiple conditions
- Choose clarity over brevity; explicit code beats clever one-liners
- Follow project coding standards from CLAUDE.md
- Avoid over-simplification that reduces maintainability or debuggability
- Focus scope: only refine recently modified code unless told otherwise
- Consolidate related logic; eliminate dead code
- Preserve helpful abstractions that improve organization
