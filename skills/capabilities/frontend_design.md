# Frontend Design

## When Active
When building web components, pages, or UI applications.

## Instructions
- Before coding, commit to a bold aesthetic direction (brutalist, retro-futuristic, editorial, organic, etc.)
- Consider purpose, audience, tone, and what makes the design memorable
- Typography: choose distinctive fonts, never generic (no Inter, Arial, Roboto); pair display + body fonts
- Color: cohesive palette with CSS variables; dominant colors with sharp accents
- Motion: prioritize CSS-only animations; staggered reveals over scattered micro-interactions
- Layout: use asymmetry, overlap, grid-breaking, generous negative space
- Backgrounds: gradient meshes, noise textures, geometric patterns, layered transparencies
- Never produce generic "AI slop" aesthetics (purple gradients on white, predictable layouts)
- Match implementation complexity to vision: maximalist = elaborate code; minimalist = precision and restraint
- Vary themes, fonts, and aesthetics across generations — never converge on common defaults
- Implement production-grade, functional, working code
